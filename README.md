# Make the AI Judge Laugh

A tiny program for the make.fun bounty "Make the AI Judge Laugh".

`main.py` writes a single one-line joke about office life to
`/output/entry.txt`. The line is fixed, so every run produces the same
output.

## Run

```sh
python3 main.py
cat /output/entry.txt
```

## The joke

> I keep a plant on my desk so when my boss asks how my workload is
> going, I can point at something else dying quietly.

117 characters, one line, UTF-8.
